Software auf Schul-PCs verteilen

Vorbereitete portable Programme aus dem lokalen Schulnetz bereitstellen

Das Problem

Schul-PC

Für die AG-Arbeit werden Programme wie Thonny, Chromium, WinPython oder PrusaSlicer benötigt. Auf einem Schul-PC ist eine herkömmliche Installation jedoch oft nicht möglich oder nicht sinnvoll: Es fehlen Administratorrechte, jeder Rechner müsste einzeln eingerichtet werden und große Downloads aus dem Internet belasten die verfügbare Verbindung.

Keine klassische Installation

Die Programme werden als vorbereitete portable Archive bereitgestellt. Sie werden nicht in die Windows-Installation eingetragen, sondern in einen gemeinsamen Programmordner entpackt.

Einheitlicher Stand

Alle Schul-PCs erhalten dieselben ausgewählten Versionen. Das reduziert Unterschiede bei Anleitungen, Unterricht und Fehlersuche.

Weniger Internetverkehr

Die Archive liegen einmal im lokalen Softwaredepot. Die PCs holen sie aus dem Schulnetz statt jedes Paket selbst aus dem Internet zu laden.

Die Lösung: lokales Softwaredepot

Der AG-Server stellt die vorbereiteten Archive im lokalen Netzwerk zur Verfügung. Das Skript ag-tool.cmd auf dem Schul-PC lädt die benötigten Pakete herunter, entpackt sie und legt sie unter C:\Users\Public\Programme\ ab. Damit wird die Software bereitgestellt, ohne dass eine klassische Installation mit erweiterten Rechten erforderlich ist. 

AG-Server
    |
    | HTTP :8000 im lokalen Netzwerk
    v
ag-tool.cmd auf dem Schul-PC
    |
    +-- curl.exe: Archive herunterladen
    +-- 7-Zip: Archive entpacken
    '-- C:\Users\Public\Programme\

So läuft die Bereitstellung ab

  1. Die vorbereiteten Softwarearchive liegen im Wartungsbereich des AG-Servers.
  2. ag-tool.cmd prüft, ob 7-Zip verfügbar ist, und stellt die benötigten Werkzeuge bei Bedarf bereit.
  3. Das Skript ruft die vorgesehenen Archive über den lokalen Server ab.
  4. Die Archive werden in den öffentlichen Programmordner entpackt.
  5. Eine Erfolgsdatei bestätigt die abgeschlossene Einrichtung und verhindert unnötige Wiederholungen.

Ergebnis der Einrichtung

Nach erfolgreichem Durchlauf wird C:\Users\Public\Programme\ag-tool-v1.0-erfolgreich.txt angelegt. Sie dient als einfache Markierung, dass die Softwarebereitstellung bereits abgeschlossen wurde.

Aktuell vorgesehene Programme

Programmarchive

  • Thonny 5.0.0 für Python
  • Chromium Portable
  • WinPython 3.14.7.0dot
  • Prusa3D für den 3D-Druck

Softwaredepot

Im Wartungsordner sind darüber hinaus Archive für Arduino IDE, Firefox und Chrome vorbereitet. Nicht jedes vorhandene Archiv wird derzeit schon durch ag-tool.cmd verarbeitet; diese Pakete gehören zur nächsten Ausbaustufe.

Grenzen und nächste Schritte

Das Verfahren ist für die AG und das lokale Schulnetz gedacht. Es ersetzt keine zentrale Softwareverteilung der Schule und setzt voraus, dass der AG-Server und seine vorbereiteten Archive erreichbar sind. Die Liste der verteilten Programme muss außerdem gepflegt und vor dem Einsatz geprüft werden.

Die vollständige Fassung mit den technischen Details befindet sich auf dem AG-USB-Stick; die großen Archive werden nicht in das GitHub-Repository übertragen.
