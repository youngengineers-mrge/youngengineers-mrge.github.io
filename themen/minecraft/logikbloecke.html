Mission: Baue erst eine digitale Schaltung mit Redstone und entwickle später einen kompakten Logikblock.

Neu: UND-Gatter – blockgenauer Baukurs mit Bildern

Baue eine vollständige Redstone-UND-Schaltung nach fünf maßstäblichen Rasterzeichnungen. Mit Materialliste, eindeutigen Koordinaten, Hebeln, Fackeln, Repeater, Lampe, Wahrheitstabelle und Fehlersuche.

→ Bebilderten UND-Gatter-Kurs öffnen

Die Schaltung ist als Unterrichtsentwurf angelegt und muss noch in Minecraft 26.2 praktisch getestet werden.

Neu: UND-Gatter als programmierbarer Minecraft-Block

Nach der Redstone-Schaltung entwickeln wir einen einzigen Block mit zwei Eingängen und einem Ausgang. Mit interaktivem Simulator, Java-Beispielen, Tests und Bauplan für die spätere Mod.

→ Interaktiven Mod-Kurs öffnen

Die Fabric-Anbindung ist noch versionsabhängig und wird nach dem ersten erfolgreichen Build vervollständigt.

1. Die Mission: Eine sichere Labortür

Unsere geheime Werkstatt soll nur geöffnet werden, wenn beide Sicherheitsschalter eingeschaltet sind. Schalter A gehört zum Laborleiter, Schalter B zur Sicherheitskontrolle. Der Ausgang Q steuert eine Lampe oder Tür.

ABQ = A UND B
000
010
100
111

0 bedeutet aus, 1 bedeutet ein.

2. Vorbereitung

  1. Öffne eine kreative Testwelt.
  2. Lege Hebel, Redstone-Staub, Redstone-Fackeln, Repeater, Redstone-Lampe und feste Baublöcke in die Schnellzugriffsleiste.
  3. Baue auf einer ebenen Fläche mit genügend Abstand zu anderen Schaltungen.
  4. Beschrifte die beiden Eingänge gedanklich mit A und B. Baue zuerst nur die Anzeige mit einer Lampe, noch keine Tür.

3. Erste Vorübung: NICHT-Gatter

  1. Platziere einen festen Block.
  2. Befestige einen Hebel an einer Seite.
  3. Befestige eine Redstone-Fackel an der gegenüberliegenden Seite des Blocks.
  4. Schalte den Hebel um. Beobachte: Hebel an → Fackel aus; Hebel aus → Fackel an.
  5. Notiere die Wahrheitstabelle mit den zwei möglichen Zuständen.

Diese Invertierung benötigen wir gleich für das UND-Gatter.

4. UND-Gatter Schritt für Schritt

Wir verwenden die Beziehung A UND B = NICHT(NICHT A ODER NICHT B) (De-Morgan-Regel).

  1. Baue zwei getrennte NICHT-Gatter wie in der Vorübung. Die Hebel sind A und B.
  2. Führe die Ausgänge der beiden NICHT-Gatter über Redstone-Staub zu einem gemeinsamen Leitungsabschnitt zusammen. Verhindere dabei, dass die Eingänge A und B selbst verbunden werden.
  3. Führe die gemeinsame Leitung zu einem festen Block, an dessen anderer Seite eine Redstone-Fackel sitzt. Diese Fackel bildet das dritte NICHT-Gatter.
  4. Verbinde den Ausgang der dritten Fackel mit einer Redstone-Lampe. Setze bei Bedarf einen Repeater in Ausgangsrichtung ein.
  5. Teste die vier Schalterstellungen aus der Tabelle. Nur bei A = 1 und B = 1 darf die Lampe leuchten.

Wichtig: Dies ist eine Funktions- und Verdrahtungsanleitung, noch keine blockgenaue Bauzeichnung. Redstone-Verbindungen können seitlich unerwartet Kontakt bekommen. Eine exakte Draufsicht und ein Bauplan mit Höhenangaben sind für den praktischen Schüleraufbau der nächste Dokumentationsschritt.

Messauftrag: Zeichne für jede Schalterstellung auf, ob die drei Fackeln leuchten und ob Q = 0 oder 1 ist.

5. Vom großen Aufbau zum einzelnen Logikblock

Unsere spätere Fabric-Mod soll denselben Zusammenhang in einem Block umsetzen. Wir definieren zuerst die Schnittstelle:

Seite (bezogen auf Blickrichtung des Blocks)Aufgabe
LinksEingang A
RechtsEingang B
VorneAusgang Q
HintenKeine Verbindung

Der Block soll gedreht werden können. Deshalb müssen die Seiten relativ zu seiner Blickrichtung berechnet werden. Ein normales Vollblockmodell allein kann das noch nicht.

6. So wird daraus später Java-Code

Das folgende Beispiel beschreibt nur die logische Berechnung. Es ist noch keine vollständige Minecraft-Blockklasse.

public static boolean und(boolean a, boolean b) {
    return a && b;
}

public static boolean oder(boolean a, boolean b) {
    return a || b;
}

public static boolean xor(boolean a, boolean b) {
    return a ^ b;
}
  1. Im Lernzweig Eigene Mods wird zunächst ein einfacher Block registriert.
  2. Danach erhält der Logikblock eine Ausrichtung und einen gespeicherten Ausgangszustand.
  3. Beim Ändern eines Nachbarblocks werden die beiden Eingangssignale abgefragt.
  4. Die Funktion und(a,b) berechnet Q.
  5. Der Ausgang muss Minecraft als Redstone-Signal bereitgestellt werden. Auch Repeater und andere Logikblöcke sollen ihn erkennen.
  6. Zuletzt werden alle vier Eingangskombinationen und alle vier horizontalen Drehungen getestet.

Diese sechs Schritte sind die Entwicklungsplanung, noch kein kopierfertiger Fabric-Code. Die konkreten Methoden hängen von der Minecraft-26.2-API ab und müssen im Mod-Projekt implementiert und kompiliert werden.

7. Zusatzmissionen

  1. ODER: Die Lampe leuchtet, sobald mindestens ein Hebel eingeschaltet ist.
  2. XOR: Die Lampe leuchtet genau dann, wenn die beiden Hebel verschieden stehen.
  3. NAND: Die Lampe ist nur bei zwei eingeschalteten Hebeln aus.
  4. Decoder: Zwei Hebel wählen genau eine von vier Lampen aus.
  5. Schloss: Vier Hebel bilden einen Binärcode, der die Tür freigibt.
