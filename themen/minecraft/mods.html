Mission: Vom leeren Java-Projekt zu einem eigenen Block in Minecraft – mit VS Code, Fabric und Gradle.

1. Entwicklungsumgebung prüfen

Wir arbeiten am Windows-PC mit VS Code und der Minecraft-Java-Instanz 26.2. Prüfe zunächst im VS-Code-Terminal:

java -version
javac -version
where.exe java
where.exe javac

Wir benötigen ein zur gewählten Minecraft-/Fabric-Version passendes JDK, das Java Extension Pack für VS Code und den Gradle Wrapper des Projekts. Die genauen Anforderungen müssen mit dem tatsächlich erzeugten Fabric-Projekt abgeglichen werden.

2. Grundprojekt erstellen

  1. Öffne fabricmc.net/develop/template/.
  2. Wähle die tatsächlich unterstützte Minecraft-Version 26.2, sofern verfügbar.
  3. Mod Name: Young Engineers Logic; Mod ID: youngengineers_logic; Package: de.mrge.youngengineers.logic.
  4. Wähle Java, keine zusätzlichen Kotlin-Optionen und für den Anfang eine gemeinsame Source-Struktur.
  5. Lade die ZIP-Datei herunter und entpacke sie z. B. nach D:\Github\Andreas519\youngengineers-logic.
  6. Öffne den Projektordner in VS Code. Die Datei build.gradle muss direkt im Projektordner liegen.

Ist 26.2 im Generator nicht auswählbar, wird nicht stillschweigend eine andere Minecraft-Version eingesetzt. Dann zuerst die Fabric-Unterstützung klären.

3. Die wichtigsten Dateien kennenlernen

Datei/OrdnerBedeutung
src/main/javaUnser Java-Programm
src/main/resources/fabric.mod.jsonMod-ID, Name, Einstiegspunkt und Abhängigkeiten
src/main/resources/assetsModelle, Texturen, Sprache
build.gradleBuild-Konfiguration
gradlew.batGradle unter Windows starten

4. Erste Erfolgsmeldung programmieren

Öffne die vom Generator angelegte Hauptklasse, die in fabric.mod.json als Einstiegspunkt steht. Ergänze in der vorhandenen onInitialize()-Methode:

System.out.println("Young Engineers Logic wurde geladen!");

Speichere die Datei und starte im VS-Code-Terminal:

.\gradlew.bat runClient

In der Konsole sollte die Meldung erscheinen. Starte Minecraft zunächst als Entwicklungsinstanz, nicht in unserer produktiven UltimMC-Welt.

5. Eigenen Block vorbereiten

Unser erster Block heißt YE-Logikblock und erhält die ID youngengineers_logic:logikblock.

  1. Lege im Java-Paket eine Klasse ModBlocks.java an.
  2. Registriere den Block und sein zugehöriges BlockItem gemäß der Fabric-Dokumentation für die tatsächlich verwendete Minecraft-Version.
  3. Rufe die Initialisierung der Blockregistrierung aus der Hauptklasse auf.
  4. Ergänze den Block im Kreativinventar.
  5. Erstelle assets/youngengineers_logic/blockstates/logikblock.json, ein Blockmodell, ein Item-Modell und eine PNG-Textur.

Ein einfaches Blockmodell mit derselben Textur auf allen Seiten:

{
  "parent": "minecraft:block/cube_all",
  "textures": {
    "all": "youngengineers_logic:block/logikblock"
  }
}

Für die Sprache lege assets/youngengineers_logic/lang/de_de.json an:

{
  "block.youngengineers_logic.logikblock": "YE-Logikblock"
}

Die Java-Registrierung ist versionsabhängig. Vor dem Kopieren von Code aus älteren Tutorials unbedingt die aktuelle Fabric-Anleitung „Deinen ersten Block erstellen“ vergleichen. Die vollständige Java-Implementierung wird erst nach Prüfung der 26.2-API festgelegt.

6. Mod bauen und testen

  1. Prüfe im Terminal mit .\gradlew.bat build, ob das Projekt ohne Fehler übersetzt.
  2. Die erzeugte Mod-JAR liegt üblicherweise unter build/libs.
  3. Starte zum Test .\gradlew.bat runClient.
  4. Erzeuge in einer Testwelt den Block mit /give @s youngengineers_logic:logikblock.
  5. Platziere ihn, baue ihn wieder ab und kontrolliere seine Darstellung.
  6. Erst nach erfolgreichem Test: kompatible JAR und erforderliche Abhängigkeiten in eine separate UltimMC-Testinstanz übernehmen.

7. Häufige Fehler

„java“ oder „javac“ wird nicht gefunden

JDK-Installation und Java-Pfade prüfen. Eine Java-Laufzeit allein reicht nicht zum Entwickeln.

Gradle kann Abhängigkeiten nicht laden

Internetverbindung, Proxy und Minecraft-/Fabric-Versionsangaben kontrollieren. Die erste Ausführung benötigt Downloads.

Der Block erscheint rosa-schwarz

Texturpfad, Blockstate, Modell-JSON und Namespace vergleichen.

Der Block existiert nicht

Registrierung, Aufruf der Initialisierung und den Eintrag im Kreativinventar prüfen.
